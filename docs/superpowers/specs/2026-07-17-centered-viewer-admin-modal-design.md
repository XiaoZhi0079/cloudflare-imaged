# 居中图片查看器与后台管理弹窗设计

## 目标

在不读取、下载、解码或分析任何图库图片的前提下，完成前台图片查看器、后台图片管理入口和首页文字层级的调整。

## 前台图片查看器

- 首页与图集详情页使用相同的 `modal-stage` 结构。
- 图片舞台作为模态层唯一参与居中布局的内容，文件名和标签绝对定位在舞台内部底部，因此文字不会再把图片推离屏幕中心。
- 文字区域完全透明，不添加白色、半透明色块或渐变背景；通过多层深色文字阴影保障在明暗画面上的基本可读性。
- 图片继续使用 `object-fit: contain` 语义和视口上限，保持完整展示，不裁剪。
- 模态层保留关闭按钮和点击遮罩关闭行为。

## 后台图片管理弹窗

- `#admin-detail-drawer` 更名为 `#admin-detail-overlay`，不再保留抽屉语义。
- 外层使用现有后台遮罩样式，动态创建的 `.admin-detail-dialog` 承担 `role="dialog"`、`aria-modal="true"` 和标题关联。
- 桌面端弹窗最大宽度 1180px，内部沿用预览/编辑双栏工作区；图片使用 `object-fit: contain` 完整展示。
- 900px 以下切换单栏；720px 以下弹窗全屏，内容内部滚动。
- 保留关闭按钮、Escape 关闭、焦点循环和关闭后焦点恢复；新增点击遮罩关闭。

## 首页信息层级与文案

- 删除前台“管理”导航入口。
- 将“标签浏览”改为“标签”。
- `ALBUMS` 与 `BROWSE` 只保留英文眉题，删除“浏览图集”和“按标签浏览”两个中文标题。
- 首页介绍文案改为：

  > 让光影在图集中成章，让细节在标签间相遇。愿每一次凝视，都能留住片刻心动。

## 缓存与发布

- 公共页面资源版本统一更新为 `20260717-centered-viewer-admin-modal`。
- 图片库页面的 `workbench.css` 与 `library-page.js` 使用同一新版本；未修改的后台公共样式继续沿用原版本。
- 通过静态 HTML/CSS/JS 断言、Node 测试、GitHub/Cloudflare 状态和线上文本响应验收；不生成或查看截图。

## 验收标准

1. 首页和图集详情页的图片与说明共同位于 `.modal-stage`，说明绝对定位且背景透明。
2. 图片舞台由全屏模态层居中，说明不会参与居中尺寸计算。
3. 后台详情是居中大弹窗，桌面双栏、平板单栏、手机全屏。
4. 前台不再出现管理入口、“标签浏览”、“浏览图集”或“按标签浏览”。
5. 新文案和资源版本在线上 HTML/CSS/JS 中可验证。
