# 管理端认证与标签筛选微调设计

日期：2026-07-14

## 目标

- 已保存有效密钥时，在图片库与内容设置之间跳转不闪现验证页面。
- 图片库标签筛选明确表现为可多选，并继续使用“全部匹配（AND）”语义。
- 删除图片库左侧整个“主分类”筛选区；没有选择标签时自然展示全部图片。

## 初始认证状态

两个管理页面的验证区域在 HTML 初始状态中保持隐藏，管理主体也继续隐藏。页面模块读取 `localStorage` 后：

- 没有密钥时显示验证区域。
- 有密钥时保持中性背景，完成接口验证后直接显示目标管理页面。
- 密钥无效、退出或任意管理请求返回 `401` 时显示验证区域。

不提前显示未经验证的管理数据，也不使用验证表单充当加载状态。

## 筛选与目录职责

- 主分类对应 R2 存储目录，不属于内容筛选维度；图片库左侧不显示主分类筛选。
- 管理端仍加载主分类数据，用于上传落盘、详情编辑、批量移动和管理端图片卡片的目录标识。
- 公开展示页的图片卡片不显示目录名称；管理端图片卡片继续显示目录名称。
- 标签使用复选框，允许同时选择多个真实标签。
- 多个标签采用交集筛选：图片必须包含所有选中标签。
- 未选择标签时，标签集合为空，不限制图片标签。
- 已选标签行使用陶土色边线和浅色背景，标题旁显示已选数量。
- “清空”清除标签和搜索条件，恢复全部图片。

## 验证

- 静态测试确认验证区域初始隐藏，且图片库模板不再包含主分类筛选区。
- 状态测试确认空筛选返回全部图片，多标签返回交集。
- 浏览器测试确认管理页面之间跳转时验证区域从未可见。
- 浏览器测试确认左侧只显示标签筛选，多个标签可以同时保持选中，选中数量与结果一致。
- 模板测试确认公开图片卡片不输出目录，管理端图片卡片保留目录标识。
