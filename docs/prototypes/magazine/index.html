进阶 · 01 + 03（脱敏素材）

用仓库内演示素材呈现：封面特刊首页 + 沉浸阅读（左右切换 / 缩略图 / 键盘）。 这是当前推荐的落地组合。

可交互 仓库素材 优先看这个

01 封面特刊

大封面进门 + 系列 chips + 一句系列说明 + 瀑布流续页。 最接近「一期杂志封面」，仪式感强，适合内容少而精。

首屏冲击强 改动中等 线框版

02 编辑墙

左系列栏 + 右杂志内页：开篇主图墙，再进入松散网格。 信息层次最丰富，像在翻编辑好的专题页。

结构感最强 改动较大 桌面更出彩

03 沉浸阅读

不重做首页结构，重点强化点开后的阅读态： 模糊底、大图、左右切换、标签与进度。网格页可继续很克制。

看图体验优先 可先做 与 01/02 可叠加
